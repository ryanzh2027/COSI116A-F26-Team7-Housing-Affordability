Data Analysis

Data Sources

We used the U.S. Census Bureau's ACS 1-Year data from 2021 to 2024. We downloaded four tables for each year:

  • B25070: Gross Rent as a Percentage of Household Income
  • B25091: Mortgage Status by Selected Monthly Owner Costs as a Percentage of Household Income
  • B19013: Median Household Income
  • B25077: Median Value of Owner-Occupied Housing Units

We also used Census geography files and CBSA boundary data for the map.

Data Types

Our data include categorical variables such as metro names, GEO_ID, and CBSA codes. Numerical variables include housing-unit counts, burden rates, median household income, and median home value. We also use year to compare data from 2021 to 2024.

Data Preprocessing

We used Python and pandas to process the original ACS files.

First, we read the ACS data and geography files for each year. We selected metropolitan areas and matched the tables using GEO_ID.

The original B25070 and B25091 tables contain housing-unit counts, so we calculated the burden rates ourselves. We used 30% of household income as the threshold.

Renter burden (%)

100 × (B25070_E007 + B25070_E008 + B25070_E009 + B25070_E010) / (B25070_E001 − B25070_E011)

Mortgage-owner burden (%)

100 × (B25091_E008 + B25091_E009 + B25091_E010 + B25091_E011) / (B25091_E002 − B25091_E012)

We excluded units where the cost-to-income ratio was not computed. For homeowners, we only included those with a mortgage.

We also calculated:

Burden gap (pp) = Renter burden − Mortgage-owner burden

For income and home value, we used B19013_E001 and B25077_E001.

We checked missing values, invalid numbers, and duplicate metro-year records. We did not replace missing values with zero.

Then we combined the four years into one dataset using CBSA codes and years. We exported the processed data to CSV files and used CBSA codes to match the data with the map boundaries.

Data Files

The processed CSV data and geographic boundary files are stored in the project's data folder. The dashboard loads these files using D3.
